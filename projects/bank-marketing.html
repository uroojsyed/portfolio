Bank Marketing — Predictive Analysis

Using exploratory data analysis, feature selection and classification models to investigate how customer data can inform more effective bank telemarketing strategies.

Python Tableau Data Analysis Data Visualization Data Cleaning Feature Selection Decision Trees Naïve Bayes Predictive Modelling

Project overview

This project was completed as the culminating assignment for CIND119, part of my postgraduate studies in Data Analytics, Big Data and Predictive Analytics at Toronto Metropolitan University.

Using the Bank Marketing dataset, which contains information about customers contacted during a Portuguese banking institution's telemarketing campaigns, the project examined how customer characteristics and campaign information could help predict whether a client would subscribe to a term deposit.

The analysis combined data exploration, visualization, data preparation and machine-learning classification to identify potentially useful predictors and compare model performance.

Research objective

Banks conduct marketing campaigns to encourage customers to subscribe to financial products. However, contacting customers without a data-informed strategy can result in inefficient outreach.

The objective of this project was to investigate whether historical campaign data could help inform a more effective telemarketing strategy.

The central question was:

How can customer and campaign data be used to predict term-deposit subscriptions and inform more targeted telemarketing decisions?

Dataset & target variable

The project used the Bank Marketing dataset, which records information associated with direct marketing campaigns conducted by a Portuguese banking institution.

The central outcome was the variable y, indicating whether a customer subscribed to a term deposit.

  1. Yes — the customer subscribed to a term deposit.
  2. No — the customer did not subscribe to a term deposit.

This made the research problem a binary classification task: predicting one of two possible subscription outcomes.

01 / Exploratory data analysis

The first stage involved examining the dataset's customer attributes and exploring how they related to the subscription outcome.

Using Python and data visualizations, we investigated relationships between individual attributes and the target variable, as well as relationships among the attributes themselves.

Analytical approach

  1. Examined the available customer and campaign attributes.
  2. Investigated relationships between individual attributes and term-deposit subscription outcomes.
  3. Used visualizations to explore patterns and associations.
  4. Considered which attributes appeared most relevant to the prediction task.

This exploratory stage helped inform the subsequent data preparation and feature-selection process.

02 / Data cleaning & feature selection

Following exploratory analysis, we prepared the dataset for predictive modelling.

This involved cleaning the data and examining the relevance of its attributes to the classification problem.

To investigate whether a smaller set of predictors could improve performance, we created a modified dataset that excluded attributes considered less significant to the prediction task.

This allowed us to compare model performance using two approaches: the full dataset and a reduced-feature version of the data.

03 / Predictive modelling

We applied two machine-learning classification algorithms to predict whether a customer would subscribe to a term deposit.

Decision Tree classification

Decision Trees classify observations through a sequence of decisions based on input attributes.

We evaluated this algorithm as one approach to predicting customer subscription outcomes.

Naïve Bayes classification

Naïve Bayes is a probabilistic classification algorithm based on Bayes' theorem, with an assumption of conditional independence between predictors given the target class.

We also tested this algorithm to investigate how well it predicted subscription outcomes.

Model comparison

Each algorithm was evaluated using both versions of the dataset: the complete set of attributes and the reduced-feature dataset.

This produced four model configurations:

  1. Decision Tree — full dataset
  2. Decision Tree — reduced-feature dataset
  3. Naïve Bayes — full dataset
  4. Naïve Bayes — reduced-feature dataset

The purpose of this comparison was to evaluate differences in predictive performance and determine whether reducing the number of input attributes improved model accuracy.

04 / Model results

Based on the results documented in my original project summary, the Naïve Bayes classifier using the reduced-feature dataset achieved the highest reported accuracy.

05 / Business implications

The project explored how predictive modelling could support more informed telemarketing decisions.

Rather than treating all customers as equally likely to subscribe, a banking institution could use historical campaign data to investigate which customer characteristics are associated with subscription.

The original project recommended prioritizing the attributes included in the reduced-feature Naïve Bayes model when developing a more targeted telemarketing strategy.

While the reported classification accuracy was promising, additional evaluation would be needed before using such a model in practice, particularly to assess how well it identifies customers who actually subscribe.

Project takeaway

This project provided practical experience in applying a complete analytical workflow to a business decision-making problem.

From investigating customer data and visualizing patterns to preparing features and comparing classification models, the project demonstrated how data analysis can inform business strategy.

It also highlighted the importance of evaluating multiple modelling approaches rather than assuming that a larger number of input features necessarily leads to better predictions.
