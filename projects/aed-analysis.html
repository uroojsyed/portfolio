Toronto Public Access AED Locations

Exploring public AED distribution and data quality using Python and Pandas.

Python Pandas Data Cleaning Exploratory Analysis Open Data
View GitHub Repository ↗

Overview

Public access Automated External Defibrillators (AEDs) are essential emergency response devices. Maintaining accurate location and equipment records can support effective tracking, inspections, and maintenance.

For this project, I analyzed the City of Toronto's 2025 AED Locations dataset to examine how AED records are distributed across organizations, divisions, and individual sites. I also investigated data quality issues that could affect the reliability of equipment records.

The project was completed as part of INF1340H – Programming for Data Science at the University of Toronto.

Dataset & tools

The dataset was obtained from the City of Toronto's Open Data portal. It contains information about publicly accessible AEDs, including organization, division, site, address, placement location, manufacturer, and model.

Using Python and Pandas in Google Colab, I inspected, cleaned, and analyzed the records to identify patterns in equipment distribution and information completeness.

View original dataset ↗

01 / Data cleaning

Before beginning the analysis, I inspected the dataset for missing information, inconsistent formatting, spelling errors, and duplicate-looking records.

I performed several cleaning operations to improve consistency while preserving records that could represent valid AED units.

  • Missing information: Standardized missing values and "TBD" entries as "Not Provided" in selected columns.
  • Inconsistent formatting: Removed extra spaces and standardized capitalization in city names.
  • Spelling errors: Corrected misspelled city names to prevent locations from being counted separately.
  • Duplicate-looking records: Retained identical records because they could represent separate AED units. Added sequential record IDs to distinguish rows.

The cleaned dataset was exported as a separate CSV file, preserving the original dataset for comparison and reproducibility.

02 / Exploratory data analysis

I conducted six exploratory analyses to better understand AED record distribution, equipment information, and data completeness.

These analyses examined AED counts by division and city, identified common and unique AED manufacturers, compared records between organizations, and located records with missing placement information.

This initial exploration helped reveal differences in how AED records were distributed and highlighted data quality issues worth investigating further.

03 / Comparative analysis

Missing placement information by organization

To compare data completeness, I calculated the percentage of AED records with missing placement information for each organization.

Rather than comparing only the number of missing records, I divided those counts by each organization's total records. This provided a proportional comparison between the City of Toronto and Safe City Program.

The analysis found that the Safe City Program had a higher proportion of records without placement information, highlighting a potential opportunity to improve record completeness.

AED distribution across individual sites

I calculated the average number of AED records per site and identified locations exceeding that average.

The analysis revealed that certain sites, including TTC stations, had substantially more AED records than the average location. These concentrations may be relevant for equipment tracking and record management.

04 / Key findings

  1. Zoll was the most frequently recorded AED manufacturer. Its prevalence provides insight into the equipment represented across the dataset.
  2. Placement data completeness varied between organizations. The Safe City Program had a higher proportion of records without specific placement information.
  3. AED records were concentrated at certain sites. Some locations, including TTC stations, had above-average record counts.
  4. Identical records were not necessarily duplicates. Without official device identifiers, identical entries could represent separate AED units, particularly at mobile locations.

05 / Limitations & reflection

A key challenge was determining how to handle records that appeared identical. Because the dataset did not include unique identifiers for individual AED devices, removing these records could have excluded legitimate equipment entries.

The dataset also contained incomplete location and placement information. Additionally, it did not include maintenance histories, device conditions, inspection statuses, or usage frequency, limiting conclusions about operational needs and actual accessibility.

This project reinforced the importance of understanding the context behind data quality issues before making cleaning decisions. It also demonstrated how exploratory analysis can identify patterns and information gaps that may support more informed public-service record management.
